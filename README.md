# Лучник — AION 2 Global

Отдельный статический сайт с гайдом лучника в оформлении [AION 2 Guides](https://couga54.github.io/aion2-guides/ru/gladiator/). Есть русская и английская версии, режимы PvE/PvP/Прокачка, поиск, подсказки умений, переключение темы и чеклист прокачки.

**Готовый сайт находится в `docs/`.** Корневой `index.html` отправляет читателя прямо на русский гайд лучника. Для GitHub Pages нужен Python только если вы захотите изменить содержание или пересобрать проект.

## Публикация на GitHub Pages

1. Загрузите **содержимое этой папки** в отдельный репозиторий GitHub.
2. В Settings → Pages выберите **Deploy from a branch**, ветку `main`, каталог `/docs`.
3. Сайт откроется по адресу `https://<имя-пользователя>.github.io/<имя-репозитория>/`.

Ссылки на страницы и ресурсы относительные, поэтому сайт работает при любом имени репозитория. Если нужен корректный `canonical`, превью для соцсетей, sitemap и кнопка «Сообщить об ошибке», пересоберите с адресами своего сайта и репозитория:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
SITE_BASE_URL="https://<имя-пользователя>.github.io/<имя-репозитория>/" \
SITE_REPO_URL="https://github.com/<имя-пользователя>/<имя-репозитория>" \
.venv/bin/python tools/build.py
```

Затем закоммитьте обновлённый `docs/`. Пока эти адреса не заданы, сайт работает, но метаданные с абсолютным URL не выводятся.

## Где менять гайд

- `src/content/ranger/ru.html` и `en.html` — текст гайда;
- `data/leveling/ranger.json` и `common.json` — чеклист прокачки;
- `data/skills/ranger.json` — названия, описания и специализации умений;
- `src/assets/css/site.css` — внешний вид;
- `data/site.json` — сведения о классе и глобальном сезоне.

После правок запустите `.venv/bin/python tools/build.py` и загрузите обновлённый `docs/`. Для локального просмотра: `python3 -m http.server 8000 --directory docs`.

PvE основан на билде Whelps и данных умений глобального клиента. PvP — предварительный вариант по данным клиента и опыту корейского сервера; после запуска Global проверьте слоты стигм, точность и шанс контроля. Подробные ссылки на источники есть на странице гайда.
